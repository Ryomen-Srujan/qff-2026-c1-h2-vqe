# Start Here

1. Open this folder in VS Code.
2. Create/activate `.venv` and install `requirements.txt` in a compatible Python environment.
3. Open and run `main.ipynb` top-to-bottom.
4. Read `report.md` before presenting results; it marks historical outputs and known validation gaps.
5. Do not overwrite your existing Git repository's `.git` folder with this archive. Copy project files into the existing folder, preserving `.git` and your `.venv`.

Processor B uses the updated Phase 1 topology in `processors/processor_b.json`. Processor D is retained as a conceptual design proposal; its benchmark is not part of the Phase 1 A/B comparison.
